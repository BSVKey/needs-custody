Works with no network

Field health records that hold up when the network is down

Each phone signs its own records: triage tags, casualties it takes over, supplies it asked for and got, vaccine deliveries it received. Nothing needs a signal. When records reach the coordinator by any route (a file over Bluetooth, a USB stick, a later link), one check shows who reached a hospital, who is not accounted for, and which orders came up short.

Before you lose signal: open this page once while you still have a connection. After that it opens from the phone itself, even in airplane mode.

Set up this phone

The coordinator gives every station the same incident code and tag salt. The salt turns triage-tag numbers into codes, so no name or tag number is ever stored.

Just looking?

Load a sample flood incident: three stations, a red casualty who arrives late, a yellow casualty who never reaches a hospital, a short IV-fluid order and a vaccine box that froze. Then open Check to see what the coordinator would see.

Sample data is made up. This page has not been used in a real response yet.

Tag a casualty

Type the number printed on the physical triage tag. If this phone already holds a triage for that number (its own, or from a records file you added on Share), this becomes a signed re-triage linked to the earlier one. Add the earlier station's file before you re-triage.

Category

Hand over tag

When this casualty leaves you, the next station takes their records straight from this phone: a QR code to scan, or sound they can hear through the air or over a walkie-talkie. They then sign that they have the casualty.

Take over a casualty

The station TAKING the casualty signs. Easiest: scan the code on the other phone, or listen to its sound, and the casualty's records come with it.

Or type it in

Use the category written on the tag as you received it. If you change the category, tag them again on the Triage tab first.

Vaccine delivery received

Load the cold box's temperature-logger file (CSV with a time column and a temperature column). The page totals the minutes outside 2 to 8 °C, and counts minutes when the logger was silent too, against a 60-minute budget. Your signed receipt carries the file's fingerprint, so the national store can check it against the raw file later.

Move records

Every record is signed, so whoever or whatever carries it can't change it unnoticed. Pick whatever works where you are.

By QR code or sound, phone to phone

How long sound takes for one casualty: about 15 to 25 seconds phone to phone, about 70 seconds over a walkie-talkie, AM radio or phone call, and nearer 2 minutes on the noisy-radio setting. Send casualties by sound; use QR codes or a file for everything else. If the other phone misses a part, play again: it keeps what it already has.

By file

Bluetooth or Nearby Share, a USB stick, a laptop, email when a link comes back.

Pass the kit itself to a phone that never had signal

Save the whole kit as one file and send it like any other file. It opens straight from the file in Chrome, Edge or Firefox on a laptop and on most Android phones. iPhones can't run a saved page, so open this page once with signal instead.

Paying a courier with no network

To pay whoever carried the file, use the BSVKey offline pay page: it hands over a signed Bitcoin BSV payment by QR code, sound or SMS, and anyone with a link broadcasts it later.
